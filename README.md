# Task 32 – To-Do List API Documentation

## Project Overview
This project documents the REST API design for a To-Do List application using Express.js concepts.

## Documentation
The `API_Documentation.md` file describes the API endpoints, HTTP methods, request bodies, expected responses, CRUD operations, error handling, and potential implementation challenges.

## API Operations
- Create a task
- Retrieve all tasks
- Retrieve a task by ID
- Update a task
- Delete a task
- Update task completion status

## Technologies
- Node.js
- Express.js
- REST API
- HTTP methods and status codes

## Purpose
The purpose of this assignment is to understand how REST APIs are planned for a To-Do List application before implementation.
